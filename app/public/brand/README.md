# Bide logo assets

Generated with the built-in imagegen tool. The transparent source is preserved in `bide-mark-source.png`; `bide-mark.png` is the optimized UI mark. App Router icons are derived from the same image: favicon (16, 32, 48 px), PNG icon (512 px), and an opaque dark Apple touch icon (180 px).

## Generation prompt

Use case: logo-brand
Asset type: production logo symbol for Bide, a Solana app where users name a price and earn while waiting.
Primary request: create one distinctive compact lowercase b monogram with two bold interlocking rounded bands suggesting patient cycles and a price order filling. Simple silhouette, large open counters, excellent legibility at 24 pixels.
Style/medium: crisp flat vector-like raster logo, premium financial interface.
Color palette: solid evergreen mint #39D9A0 mark, matching the site's dark navy and evergreen identity.
Composition/framing: one centered symbol occupying 80% of a square canvas, balanced generous margins.
Constraints: actual transparent background; symbol only; no wordmark, lettering beyond the monogram, no gradients, shadows, mockups, thin lines, border or watermark.
